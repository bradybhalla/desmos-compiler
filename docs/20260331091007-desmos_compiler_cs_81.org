*** DONE finish generate output pass

*** DONE Languages Refactor
I wanted to make the languages slightly different so hopefully future
optimizations will be much easier. I now keep instructions in blocks by label,
handle conditionals in a way that integrates into Desmos more easily, and handle
control flow slightly differently. I also separated out some logic into separate
passes (namely for computing live registers and extracting register info). These
two passes are still very basic but at least they are their own passes so can be
made more complex in the future.
